# Archived migration helpers

These files preserve the pre-reorganization helper source for historical
reference. They are deliberately stored with the `.disabled` suffix and are
not part of the CastleX workflow:

- `install_castlex_plugins.sh.disabled` downloaded third-party Obsidian plugin
  releases into an arbitrary destination.
- `sync_castlex_background.sh.disabled` copied a generated background directly
  to staging and iCloud targets.

Do not execute these archived files. Use `pull-vault.sh`, `deploy-system.sh`,
`sync-content.sh`, and `verify-system.sh` instead.
